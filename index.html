03 / UNDER THE HOOD

Clone, run, have fun.

Every 3bitFun release lives in the open. No accounts, no installs, no waiting — just open a file and play. Here's what that looks like in a terminal.

  • Zero install — every game is web hosted.
  • Zero accounts — no logins, no telemetry, no nonsense.
  • Zero waiting — everything ships on GitHub Pages, globally cached.
3bitfun — bash
