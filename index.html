02 / UNDER THE HOOD

Clone, run, have fun.

Every 3bitFun release lives in the open. No accounts, no installs, no waiting — just open a file and play. Here's what that looks like in a terminal.

  • Zero install — every game is a single HTML file.
  • Zero accounts — no logins, no telemetry, no nonsense.
  • Zero waiting — everything ships on GitHub Pages, globally cached.
3bitfun — bash
tasq@3bitfun:~/arcade$ git clone https://github.com/3bitFun/fun.git
Cloning into 'fun'... resolving deltas: 100% done.
tasq@3bitfun:~/arcade$ cd fun && ls
stacks/ doodl/ robokombat/ index.html
tasq@3bitfun:~/arcade$ ./play.sh stacks/

[STACKS] Block cadence calibrated. ✓
[STACKS] OVERHANGS: RESPECT THEM. ✓
